# Roadmap

1. Foundation and local persistence.
2. Wardrobe CRUD, categories, search and filters.
3. Optional private body/style profile.
4. Outfit builder with transparent local matching rules.
5. Calendar/history and portable backups.
6. Optional consent-based cloud sync.
7. Accessibility, PWA polish, deployment and real-device verification.

Never treat a feature as verified until its build and user-facing behavior have been tested.
