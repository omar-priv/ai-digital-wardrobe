# خزانتي — AI Digital Wardrobe

خزانة ملابس رقمية بواجهة عربية RTL، تركّز على الخصوصية والتخزين المحلي أولاً.

## الموجود حالياً
- إضافة وتعديل وحذف قطع الملابس مع الصور والتصنيف واللون والموسم والملاحظات.
- بحث وفلاتر حسب التصنيف.
- تخزين الصور والبيانات في IndexedDB على جهازك.
- اقتراح تنسيقات محلية بدون API خارجي.
- ملف شخصي اختياري وملاحظات ستايل محفوظة محلياً.
- تصدير واستيراد نسخة احتياطية JSON.

## التشغيل
يتطلب Node.js حديثاً: npm install ثم npm run dev.
للبناء: npm run build.

## الخصوصية وحدود التخزين
لا يتم رفع الصور أو البيانات تلقائياً. بيانات IndexedDB مرتبطة بالمتصفح والجهاز؛ حذف بيانات الموقع قد يحذف الخزانة. استخدم النسخ الاحتياطي بانتظام. لا يوجد تزامن تلقائي بين الأجهزة.

يمكن نشر الواجهة الثابتة على Cloudflare Pages، لكن الاستضافة المجانية لها حدود وليست ضمان uptime غير محدود. راجع PROJECT_STATUS.md وdocs/ARCHITECTURE.md.
