# خزانتي — AI Digital Wardrobe

خزانة ملابس رقمية عربية RTL، بتصميم هادئ يشبه أرشيف الملابس الشخصي، وخصوصية Local-first.

## المزايا الحالية
- إضافة وتعديل وحذف قطع الملابس مع صورها.
- تصنيفات وبحث حسب اسم القطعة أو لونها، مع فلاتر.
- حفظ الصور والبيانات في IndexedDB على نفس الجهاز والمتصفح.
- اقتراحات تنسيق محلية بسيطة من الملابس الموجودة.
- ملف شخصي اختياري للطول وملاحظات الستايل.
- تصدير نسخة احتياطية JSON واستيرادها ودمجها مع القطع الموجودة.
- واجهة عربية RTL متجاوبة، وتنقل سفلي واضح على الهاتف.

## التقنية
- React 18 + TypeScript + Vite 6.
- IndexedDB للتخزين المحلي.
- Lucide icons.
- لا يوجد Backend أو AI API في الوظائف الأساسية.

## التشغيل محلياً
يتطلب Node.js 22 أو أحدث:
```bash
npm install
npm run dev
```

فحص TypeScript وإنشاء نسخة الإنتاج:
```bash
npm run build
npm run preview
```

## النشر
يمكن نشر ملفات `dist` على استضافة صفحات ثابتة مثل Cloudflare Pages. الاستضافة المجانية لها حدود وليست ضمان uptime غير محدود. بيانات IndexedDB لا تنتقل تلقائياً بين الأجهزة.

## الخصوصية
لا يتم رفع صور الملابس أو معلومات الملف الشخصي تلقائياً. البيانات محفوظة في المتصفح على الجهاز الحالي؛ مسح بيانات الموقع أو تغيير المتصفح قد يؤدي لفقدانها. صدّر نسخة احتياطية بشكل دوري.

## تعليمات الوكلاء
اقرأ `AGENTS.md` و`DESIGN.md` و`DESIGN_SYSTEM.md` و`PROJECT_STATUS.md` و`CODE_REVIEW.md` قبل أي تعديل. توجد مهارة مراجعة شاملة في `.agents/skills/wardrobe-full-audit/SKILL.md`، وفهرس المهارات في `.agents/skills/README.md`.

**حالة التحقق:** تمت مراجعة المصدر وتحديثه، لكن لا تعتبر النسخة مجرّبة حتى ينجح `npm run build` واختبارات المتصفح على أحجام مختلفة.
## الاختبارات
تشغيل اختبارات المنطق والتخزين المحلي:
```bash
npm test
```

فحص TypeScript وإنشاء نسخة الإنتاج:
```bash
npm run build
npm run preview
```

## مهارات مراجعة المشروع
تمت إضافة مهارات محلية لمراجعة الكود وتصحيح الأخطاء، وتدقيق المعمارية والأمان والخصوصية، وكتابة الاختبارات، ومراجعة التصميم وRTL وإمكانية الوصول. ابدأ من `.agents/skills/wardrobe-full-audit/SKILL.md`، والفهرس الكامل في `.agents/skills/README.md`.

ملاحظة: هذه المهارات تعليمات للوكيل وليست اختبارات آلية بحد ذاتها. وجودها لا يعني أن مراجعة المتصفح أو قارئ الشاشة تمت. لا يوجد حالياً package-lock.json؛ لذلك التثبيت غير مثبت بالكامل حتى تتم إضافة ملف القفل.
